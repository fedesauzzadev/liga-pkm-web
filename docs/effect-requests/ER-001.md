# ER-001: Introducción de Entrenador en combate

**Propuesta:** Añadir una fase de presentación de entrenador al inicio de los combates de gimnasio, imitando el estilo clásico de Game Boy.

**Carta/Contexto:** 
- Combates de gimnasio (Gimnasios).
- El líder debe aparecer antes de sacar a su primer Pokémon.

**Descripción:**
1. Al dispararse `BattleStarted` (tipo `gym`), el sistema detecta el id del líder.
2. Se muestra el sprite del entrenador en la zona del rival.
3. Se añade un cuadro de texto (textbox) breve con el nombre del líder o su frase de desafío (a definir si el contenido ya tiene frases).
4. El entrenador "desaparece" o se mueve a un lateral y luego aparece el Pokémon.

**Propuesta técnica:**
- Crear un nuevo evento en el motor: `TrainerAppeared`.
- Extender `BattleStage` y `BattleChoreographer` para manejar este evento.
- Añadir sprites de entrenadores al manifiesto (o verificar si se pueden reutilizar los assets existentes).
- Mantener la compatibilidad con `reducedMotion` (si está activo, ir directo al Pokémon).

Estado: aprobado (resuelto 2026-10-27)

**Notas:**
- Esta es una mejora cosmética que impacta en `BattleScene` y la coreografía.
- No debe interferir con la lógica de turno.
