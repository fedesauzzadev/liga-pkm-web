# Plan T-004 — RNG con semilla + log de dados + comandos/eventos base

Spec: `specs/SPEC-A-foundations.md` §T-004 · Deps: T-001 (DONE) · Modelo: L

## Alcance
Infraestructura núcleo del motor (SDD §3): `Rng` determinista (mulberry32), tipos base
`Command`/`GameEvent`/`Decision`, `GameState` mínimo con `pending` y log de dados,
`applyCommand` (reductor puro → eventos, sin mutar entrada), `legalCommands` y `replay`.

## ACs
- AC-1 `createRng(seed)` determinista (mulberry32); `d6()` ∈ 1-6; distribución razonable (test laxo).
- AC-2 `applyCommand` devuelve `{state,events}` sin mutar el estado de entrada (`Object.freeze` profundo).
- AC-3 Toda tirada emite `DieRolled{purpose,value}`; `replay(seed, commands)` reproduce estado y eventos idénticos.
- AC-4 Tipos `Command`, `GameEvent`, `Decision` exportados; `legalCommands` existe (pocos comandos en esta etapa).

## Diseño
- `packages/engine/src/rng.ts` — `interface Rng { d6(): Face; snapshot(): number }`, `createRng` mulberry32;
  `createRng(rng.snapshot())` reanuda la secuencia (soporta guardados futuros).
- `packages/engine/src/errors.ts` — `EngineError` tipado (código) + `Result<T,E>`.
- `packages/engine/src/events.ts` — `DiePurpose` (move|attackSelect|gate|effect|wake|dodge|bonus, SDD §3),
  `DieRolled`, `GameEvent` (unión extensible).
- `packages/engine/src/commands.ts` — `Command` base: `{type:'Advance'}` (motor avanza sin decisión pendiente)
  y `{type:'Roll'}` (dado de movimiento; semántica completa en T-011).
- `packages/engine/src/state.ts` — `Decision` (ChoosePath/StopOrContinue/FightOrRelease/CaptureOrRelease/
  ChooseAttack, SDD §5), `GameState { version, turn, phase, pending, dieLog }`, `createInitialState`.
  Jugadores/equipo llegan con T-010 (sin invadir su alcance).
- `packages/engine/src/engine.ts` — `Ctx { content, rng }`; registro de handlers por `command.type`
  (Strategy+Registry, estándar §1; exhaustivo por tipos); `applyCommand`, `legalCommands`, `replay`.
  Estado inmutable con `immer` dentro de los handlers (estándar §1).
- Tests: `tests/t004-rng-commands.test.ts` — un test por AC, carga contenido real con `loadContent`.

## Fuera de alcance
Máquina de turnos, Setup/jugadores (T-010), movimiento real del dado (T-011), Logger (T-006),
invariantes automáticas (T-006), fast-check (T-006).
