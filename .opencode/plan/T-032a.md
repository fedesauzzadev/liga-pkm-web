# Plan T-032a — Escena de combate + carta TCG + carta rival

Fuente: `specs/SPEC-D-ui.md` §T-032a, `docs/adr/ADR-6-battle-presentation.md`, SDD §7.
Todo va en `apps/web/src/battle/` (chunk lazy, AC-8). La UI es prop-driven (el wiring a eventos/store es T-032d); hoy se monta con un fixture demo desde App.

## Archivos
- `battle/model.ts` — helpers puros: `attackRows(card,pkm,firstTurn)` (legal + motivo `cost`|`firstTurn` usando `canUse`/`legalAttacks` de `@liga/engine`), `attackForDie(card,value)` (rollFaces → fila, null ⇒ "no ataca"), `facesLabel`, `damageLabel` ("(10) 4-5-6 (20)"), `statusViews(conditions)` (dormido/envenenado/no atacará/(-10)).
- `battle/sprites.ts` — tipo `SpritesManifest` ({dex:{front,back}}), `useSprites()` (fetch `/sprites/sprites.json`, SSR-safe, null si falta), `spriteUrl`.
- `battle/icons.tsx` — `ElementIcon` (color+código corto por elemento, aria-label), `CostIcons` ('any' = círculo gris), `StatusIcon` (tooltip vía title).
- `battle/HpPlate.tsx` — placa nombre + HP actual/máx + barra con tween 600 ms (transition transform, `ANIMATION_CONFIG.hpTweenMs` en `events/anim.config.ts`) + íconos de estado.
- `battle/PkmCard.tsx` + `.module.css` — carta desde datos: marco por mazo (`data-deck`), nombre, HP, elemento, arte (sprite o tarjeta con nombre), filas de ataque (rollFaces, daño, costo), estados `data-state` normal/selected/disabled(+motivo)/raised, fila `data-lit` con valor del dado; preview de efecto (rawText) al seleccionar + botón "Usar".
- `battle/BattleMenu.tsx` — Atacar/Poción/Retirar/Dejar ir; modo captura: Capturar/Dejar ir (≥ 44 px).
- `battle/BattleScene.tsx` + `.module.css` — capas en orden `data-layer`: fondo → sprites (rival arriba-derecha `data-side="rival"`, jugador abajo-izquierda) → FX (`pointer-events:none`, capa vacía para T-032c1/d) → HUD placas/caja de texto → bandeja de carta + mesa del dado (`Die3D` reutilizado, propósito "Dado de ataque"). Responsive 360×640 (carta hoja inferior) / escritorio (carta a la izquierda). `attackSelectValue` ilumina fila rival o muestra "no ataca".
- `battle/demo.ts` — fixture demo (Squirtle con 2 agua equipadas vs Poliwag) desde `content/pokemon/_samples.json`.
- `App.tsx` — botón demo "Combate" que monta `lazy(() => import('./battle/BattleScene'))` dentro de `Suspense` (AC-8).
- `i18n/es.ts` — textos nuevos (menú, motivos, estados, elementos, "no ataca", "Usar").

## Reglas
- Sin JS de combate en bundle inicial; sin `Math.random` en lógica de presentación; animaciones solo `transform`/`opacity`; archivos ≤ 400 líneas; textos en `es.ts`; `pnpm verify` verde.
- Responsive visual (360×640) y sprite real: los verifica el dueño en OWNER-REVIEW (proxy SSR como T-032b/c0).
