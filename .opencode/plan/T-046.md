# Plan T-046 — Mapeo de ataques a movimientos oficiales (`pnpm map-moves`)

Spec: `specs/SPEC-E-content-tools.md` §T-046 · Deps: T-041 (REVIEW), T-045 (REVIEW) · Modelo: M

## Alcance
- AC-1 `pnpm map-moves`: para cada ataque **sin mapeo** (sin `officialMove` o
  `officialMoveStatus:"unmapped"`) de `content/pokemon/**` + `_staging/**`, propone
  `officialMove` + `fx` y deja `officialMoveStatus:"proposed"`. Sin candidato confiable
  ⇒ `officialMoveStatus:"unmapped"` (cae al arquetipo, FX-ADAPTER §Mapeo).
- AC-2 `/admin/cards`: botón **Confirmar mapeo** (`verified`, requiere `officialMove`);
  cambiar el mapeo lo baja a `proposed`; vista previa `playMoveFx` sobre sprites de
  ejemplo ya existe (FxPreview de T-040) — se reusa sin tocarla.
- AC-3 Informe: # verificados / propuestos / sin mapear.

## Decisiones
- **Determinista, sin LLM**: la spec pide nombre + texto + elemento + tabla ES↔EN de
  T-045; FX-ADAPTER menciona LLM pero la spec manda. Matching con `normalizeName`
  (reference.ts) contra `nameEs`/`nameEn` de `content/reference/pokeapi/moves.json`:
  - base 100: nombre exacto (ES o EN) o mismo set de tokens (cubre orden distinto,
    "Doble bofetón" ↔ "bofetón doble").
  - base 70: contención de un nombre en el otro (len ≥ 4).
  - tokens compartidos (len ≥ 4, nombre + rawText vs nombre ES+EN): 15 c/u, tope 60.
  - proponer sii `base ≥ 70` **o** (`base ≥ 40` y elemento casa vía `typeToElement`).
  - empates → id alfabético (determinismo).
- `fx`: arquetipo por elemento del movimiento (tabla local espejo de
  `defaultFxByElement`, que vive en apps/web y no es importable desde tools); solo si
  el ataque no tiene `fx`.
- Ataques ya mapeados (`proposed`/`verified`/sin status) no se tocan ⇒ idempotente.
- `moves.json` ausente ⇒ error claro + exit 1 ("corré pnpm pokeapi").
- Escritura: JSON indent 1 + `\n` final (mismo formato que `admin/server.ts`);
  conserva `_comment`/`pending`/campos existentes; solo archivos modificados.
- Patrón T-045: núcleo puro exportado en `tools/map-moves.ts` + CLI gated por
  `invokedDirectly`; flags `--dir content` y `--dry-run` (informe sin escribir).
- AC-2: `confirmMoveMapping()`/`setOfficialMove()` puras en `draft.ts` (testeables sin
  DOM, patrón t040); `AttackEditor` agrega el botón y el downgrade al editar; strings
  en `es.ts`.

## Fuera de alcance

(T-032c2), chequeos extra en `content:validate`.
