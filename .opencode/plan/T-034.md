# Plan T-034 — Inicio, setup, guardado, ajustes

Spec: `specs/SPEC-D-ui.md` §T-034. Deps: T-030 (REVIEW). Modelo: S.

## Alcance
Flujo real de partida en `apps/web/src/game/`: título → setup (1 de 5 iniciales,
semilla opcional) → juego con el motor cableado al store (RollMove, ChoosePath,
StopHere, ContinueMoving, Advance, ReleaseWild) + guardado automático en
`localStorage` con verificación de hash y ajustes persistentes. La UI es
presentacional; la sesión (newGame + log de comandos + restore) vive en funciones
puras `session.ts` sobre el motor.

## ACs → archivos
- AC-1 Título (Nueva partida / Continuar / Ajustes) → `TitleScreen.tsx`;
  setup con carta y descripción de cada inicial (elemento, PS, ataques) y
  semilla opcional → `SetupScreen.tsx`; opciones derivadas de
  `content.ts#starterOptions` (engine exporta `STARTER_BY_DECK`; los iniciales
  sin carta en el contenido quedan deshabilitados con aviso).
- AC-2 `{version, seed, starterDeck, commandLog, stateHash}` en localStorage →
  `save.ts` (Zod en la frontera, hash FNV-1a del JSON canónico, storage
  inyectable); restore determinista + verificación de hash → `session.ts`;
  versión desconocida ⇒ mensaje claro en el título; autosave a cada comando
  (superset de "por turno", cubre OWNER-REVIEW "cerrar y volver").
- AC-3 Ajustes (velocidad 1×/2×/skip, sonido placeholder deshabilitado,
  reducir movimiento aplicado al EventPlayer, semilla visible) →
  `settings.ts` + `SettingsScreen.tsx`.
