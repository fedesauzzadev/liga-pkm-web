- AC-1: salida determinista y ≤ 200 líneas.

## Pasos
1. `tasks/BACKLOG.md`: T-005 → `DOING`.
2. Test primero: `tests/t005-digest.test.ts` (`// AC: SPEC-A/T-005/AC-1`).
3. `tools/digest.ts` reemplaza el placeholder `tools/digest.mjs`:

5. `pnpm digest` ≤ 200 líneas y `pnpm verify` verde.
