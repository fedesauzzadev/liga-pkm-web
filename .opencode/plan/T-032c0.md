## Alcance
- **Licencia**: LICENSE del cliente Showdown re-verificado (AGPL-3.0 vía GitHub API + texto completo).
  Condiciones del puerto registradas en ASSETS.md + OPEN-QUESTIONS (uso privado OK).
- **Shim** (`apps/web/src/fx/showdown/`): capa de compatibilidad mínima con la API que usa la
  mayoría de las animaciones de `battle-animations-moves.ts`: `scene.showEffect(img, start, end,
  transition, after)`, `scene.backgroundEffect(color, dur, opacity?, delay?)`, `actor.anim(end,
  transition?)`, `actor.delay(ms)`, `actor.x/y/z`, `leftof()/behind()`, easings de PS
  (linear/swing/accel/decel/ballistic*/quad*), pos() 210/245 con z→escala. Diferencia clave: PS
  anima `left/top/width/height` (layout); el shim lo traduce a **solo `transform`+`opacity`**
  (translate3d+scale, transform-origin 0 0) vía WAAPI con keyframes muestreados (≤ 40 elementos,
  presupuesto de ENGINEERING-STANDARDS). Host abstracto (`FxHost`/`FxElement`) ⇒ testeable con
  elementos simulados, sin jsdom (patrón que reusa T-032c2). `speed` divide duraciones;
  `reducedMotion`/skip ⇒ destello mínimo en el defensor (FX-ADAPTER); `AbortSignal` cancela.
- **6 movimientos porteados** (números fieles al código real; bubble=bubblebeam,
  vinewhip=powerwhip, scratch=slashattack, doubleslap=xattack): `bubble.ts`, `flamethrower.ts`,
  `scratch.ts`, `vinewhip.ts`, `thunderbolt.ts`, `doubleslap.ts` + `registry.ts` (Map id→anim).
- **Demo `/dev/fx`** (lazy `import()`): escena 640×360 escalada, sprites reales frente/espalda
  desde `sprites.json` (fallback tarjeta con nombre), 2 selects (5 iniciales), botón por
  movimiento, velocidad 1×/2×/skip, toggle reduced-motion, sonda de FPS/picos y contador de
  elementos activos (medición paso 4; verificación visual en navegador la hace el dueño en GS).
- **Assets**: agregar `leaf1`/`leaf2` (los usa powerwhip) a `tools/assets.config.json` y correr
  `pnpm assets` (ampliar lista fx sin tocar código, según reporte T-043).
- **Informe** `tasks/reports/T-032c0.md`: licencia, API del shim, medición, decisión DOM vs
  canvas, tabla de dificultad por movimiento y recomendación (AC-3).
